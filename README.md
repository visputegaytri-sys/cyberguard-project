# CyberGuard — Cyber Security Threat Detection & Incident Response System

A mini-project demo based on the supplied CyberGuard project report.

## Features
- Role-based demo login
- Security dashboard
- Threat detection feed
- Severity: Low / Medium / High / Critical
- Automatic incident ticket creation for High/Critical threats
- Incident status workflow
- Endpoint health
- Compliance/security scores
- Threat simulation form
- SQLite database

## Run on Windows
1. Install Python 3.10+.
2. Open Command Prompt in this folder.
3. Run: `python -m pip install -r requirements.txt`
4. Run: `python app.py`
5. Open: http://127.0.0.1:5000
